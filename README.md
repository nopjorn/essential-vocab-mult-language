# ศัพท์จำเป็น · Essential Vocab

เกมจำคำศัพท์จำเป็นหลายภาษา เป็นเว็บแอป static ล้วน รันบน **GitHub Pages** ได้ทันทีโดยไม่ต้อง build
ออกแบบมาให้ใช้บน **iPhone (รวมถึง Pro Max)** และ **iPad** โดยเฉพาะ และติดตั้งเป็นแอปบนหน้าโฮมได้ (PWA ใช้งานออฟไลน์ได้)

- ภาษาที่เรียนได้ตอนนี้: 🇬🇧 อังกฤษ (14 ชุด 308 คำ) และ 🇰🇷 เกาหลี (15 ชุด 325 คำ พร้อมคำอ่านโรมัน)
- ภาษาคำแปล: ไทย (ชุดภาษาเกาหลีมีคำแปลภาษาอังกฤษด้วย จึงเรียน เกาหลี → อังกฤษ ได้)

## โหมดเกม

| โหมด | วิธีเล่น |
|---|---|
| 🃏 แฟลชการ์ด | พลิกการ์ดดูความหมาย แล้วกด "จำได้แล้ว" หรือ "ยังจำไม่ได้" |
| 🔤 เลือกความหมาย | ดูคำศัพท์ แล้วเลือกคำแปลที่ถูกจาก 4 ตัวเลือก |
| 🔁 เลือกคำศัพท์ | ดูคำแปล แล้วเลือกคำศัพท์ที่ถูก |
| 🎧 ฟังแล้วตอบ | ฟังเสียงอ่าน แล้วเลือกคำแปล |
| ⌨️ พิมพ์คำศัพท์ | ดูคำแปล แล้วพิมพ์คำศัพท์ (ภาษาเกาหลีพิมพ์เป็นฮันกึลหรือคำอ่านโรมันก็ได้) |
| 🧩 จับคู่ | จับคู่คำศัพท์กับคำแปลทีละ 6 คู่ |

ระบบทบทวนใช้กล่อง Leitner: ตอบถูกแล้วคำจะเลื่อนขึ้นไปกล่องถัดไป ตอบผิดจะกลับไปกล่องแรก ระบบจะสุ่มคำที่ยังจำไม่ได้หรือยังไม่เคยเห็นมาให้บ่อยกว่า
ความคืบหน้าเก็บไว้ในเครื่อง (localStorage) และหน้าตั้งค่าจะแสดงว่าแต่ละชุดจำได้แล้วกี่คำ

## ใช้บน iPhone / iPad

1. เปิดลิงก์ GitHub Pages ใน Safari
2. แตะปุ่ม **แชร์** แล้วเลือก **เพิ่มไปยังหน้าจอโฮม**
3. เปิดจากไอคอนบนหน้าโฮม แอปจะแสดงเต็มจอและใช้งานออฟไลน์ได้

สิ่งที่ปรับไว้สำหรับ iOS/iPadOS:
- เว้นระยะตาม safe area (Dynamic Island และแถบโฮม) และรองรับทั้งแนวตั้งและแนวนอน
- จอ iPad แนวนอนจะแสดงหน้าตั้งค่าเป็น 2 คอลัมน์ และแสดงตัวเลือกคำตอบเป็นตาราง 2×2
- ปุ่มสูงอย่างน้อย 44–48pt, ไม่ซูมเองเมื่อแตะสองครั้งหรือพิมพ์, รองรับโหมดมืด
- ออกเสียงด้วยเสียงในตัวของระบบ (Web Speech API) ถ้าไม่มีเสียงภาษาเกาหลี ให้ไปที่ การตั้งค่า › การช่วยการเข้าถึง › เนื้อหาที่พูด › เสียง › เกาหลี เพื่อดาวน์โหลด
- ใช้กับ iPad ที่ต่อคีย์บอร์ดได้ โดยกด 1–4 เพื่อเลือกคำตอบ และ Enter/Space เพื่อไปข้อต่อไปหรือพลิกการ์ด

## ลิขสิทธิ์และการนำไปใช้เชิงพาณิชย์

- **ชุดคำศัพท์** (`data/`) เขียนขึ้นใหม่ทั้งหมดสำหรับโปรเจกต์นี้ และเผยแพร่แบบ **CC0 1.0 (สาธารณสมบัติ)** จึงนำไปใช้ แก้ไข หรือขายได้ฟรีโดยไม่ต้องใส่เครดิต (ดู [`data/LICENSE`](data/LICENSE))
- **โค้ด** ใช้สัญญาอนุญาต **MIT** (ดู [`LICENSE`](LICENSE))
- เสียงอ่านมาจากเสียงในตัวของอุปกรณ์ผู้ใช้ แอปไม่ได้แจกจ่ายไฟล์เสียง

ชุดคำศัพท์ที่ตั้งใจ **ไม่** นำมาใช้:
- Oxford 3000/5000: ติดลิขสิทธิ์ของ Oxford University Press
- NGSL / NAWL: เผยแพร่แบบ CC BY-SA ซึ่งต้องใส่เครดิตและบังคับให้งานที่ดัดแปลงใช้สัญญาอนุญาตเดียวกัน
- รายการคำศัพท์ TOPIK หรือของสถาบันภาษาเกาหลีแห่งชาติ: เงื่อนไขการใช้เชิงพาณิชย์ไม่ชัดเจน

ถ้าจะเพิ่มคำศัพท์ ให้เขียนขึ้นเองหรือใช้แหล่งที่เป็น CC0/สาธารณสมบัติเท่านั้น

## โครงสร้างโปรเจกต์

```
index.html              หน้าแอป (meta สำหรับ iOS, PWA)
manifest.webmanifest    ข้อมูล PWA
sw.js                   service worker สำหรับใช้งานออฟไลน์
assets/css/style.css    สไตล์ (responsive สำหรับ iPhone/iPad, โหมดมืด)
assets/js/app.js        หน้าตั้งค่า, เกมทุกโหมด, หน้าสรุปผล
assets/js/i18n.js       ข้อความ UI (ไทย/อังกฤษ)
assets/js/store.js      การตั้งค่าและความคืบหน้า (localStorage)
assets/js/speech.js     การออกเสียง
data/languages.json     รายชื่อภาษาที่เรียนและภาษาคำแปล
data/vocab/<code>.json  ชุดคำศัพท์ของแต่ละภาษา
scripts/validate.mjs    สคริปต์ตรวจข้อมูลคำศัพท์
```

### รูปแบบไฟล์คำศัพท์

```json
{
  "code": "ko",
  "name": { "th": "เกาหลี", "en": "Korean" },
  "nativeName": "한국어",
  "speech": "ko-KR",
  "license": "CC0-1.0",
  "sets": [
    {
      "id": "greetings",
      "icon": "👋",
      "name": { "th": "คำทักทายและวลีพื้นฐาน", "en": "Greetings & basic phrases" },
      "words": [
        { "term": "안녕하세요", "roman": "annyeonghaseyo", "tr": { "th": "สวัสดี", "en": "hello" } }
      ]
    }
  ]
}
```

- `term`: คำศัพท์ในภาษาที่เรียน
- `roman` (ไม่บังคับ): คำอ่านโรมัน
- `tr`: คำแปล แยกตามรหัสภาษา
- `note` (ไม่บังคับ): หมายเหตุ แยกตามรหัสภาษา จะแสดงหลังตอบ

### เพิ่มภาษาที่จะเรียน (เช่น ญี่ปุ่น)

1. สร้างไฟล์ `data/vocab/ja.json` ตามรูปแบบข้างบน
2. เพิ่มรายการใน `learn` ของ `data/languages.json`
3. เพิ่มไฟล์ใหม่ในรายการ `CORE` ของ `sw.js` แล้วเปลี่ยน `VERSION`
4. รัน `node scripts/validate.mjs`

### เพิ่มภาษาคำแปล (เช่น แปลเป็นภาษาญี่ปุ่น)

1. เพิ่มคำแปลในทุกคำ เช่น `"tr": { "th": "...", "ja": "..." }`
2. เพิ่มรายการใน `translate` ของ `data/languages.json`
3. (ไม่บังคับ) เพิ่มข้อความ UI ของภาษานั้นใน `assets/js/i18n.js` ถ้าไม่มี UI จะแสดงเป็นภาษาไทย

ตัวเลือก "แปลเป็นภาษา" ในหน้าตั้งค่าจะแสดงเฉพาะภาษาที่ทุกคำในชุดนั้นมีคำแปลครบ

## รันในเครื่อง

```bash
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```

ถ้าจะทดสอบบน iPhone/iPad ให้เปิด `http://<IP ของคอมพิวเตอร์>:8000` จากเครื่องที่อยู่ใน Wi-Fi เดียวกัน (service worker ทำงานเฉพาะบน HTTPS เช่น GitHub Pages)

## Deploy บน GitHub Pages

มี workflow ที่ `.github/workflows/pages.yml` ซึ่งจะตรวจข้อมูลและ deploy ทุกครั้งที่ push ไปที่ `main`
ตั้งค่าครั้งแรก: ไปที่ **Settings › Pages › Build and deployment › Source** แล้วเลือก **GitHub Actions**
