# ศัพท์จำเป็น · Essential Vocab

ออกแบบมาให้ใช้บน **iPhone (รวมถึง Pro Max)** และ **iPad Air** โดยเฉพาะ เพิ่มไปยังหน้าจอโฮมได้ และใช้งานออฟไลน์ได้

## ฟีเจอร์

- **หน้าตาแบบแอปมือถือ**: แถบเมนูไอคอนด้านล่าง (หน้าหลัก · ความคืบหน้า · ปุ่มเริ่มฝึกตรงกลาง · คู่มือ · ตั้งค่า) หัวข้อหน้าใหญ่แบบ iOS และเกมเปิดเต็มจอ
- **หน้าหลัก**: สลับภาษาด้านบน การ์ดสรุปความคืบหน้า เลือกโหมดเกม เลือกระดับ (1–3) และเลือกชุดคำศัพท์ (ได้หลายชุด หลายระดับ)
- **รายการคำศัพท์ของชุด**: แตะไอคอนรายการที่แถวของชุดเพื่อดูคำทั้งหมด พร้อมคำอ่าน คำแปล และเสียง แตะวงกลมท้ายคำเพื่อทำเครื่องหมาย "รู้คำนี้แล้ว" และกด "ฝึกชุดนี้" เพื่อเล่นเฉพาะชุดนั้น
- **ปุ่มเริ่มฝึก**: ปุ่มวงกลมตรงกลางแถบเมนู กดได้จากทุกหน้า
- **6 โหมดเกม**: แฟลชการ์ดแบบปัด (ปัดขวา = จำได้, ปัดซ้าย = ยังจำไม่ได้) · เลือกความหมาย · เลือกคำศัพท์ · ฟังแล้วตอบ · พิมพ์คำศัพท์ · จับคู่
- **ระบบทบทวนแบบ Leitner**: ระดับความจำ 0–5 คำที่ยังจำไม่ได้จะถูกสุ่มมาบ่อยกว่า
- **หน้าความคืบหน้า**: ภาพรวมทุกภาษาและแยกรายภาษา มีคำที่จำได้ ความแม่นยำ วันเรียนต่อเนื่อง กราฟ 14 วัน ความคืบหน้าแยกชุด คำที่ผิดบ่อย (กดฝึกได้ทันที) และประวัติการเล่น
- **หน้าตั้งค่า**: ภาษาคำแปลและภาษาของแอป จำนวนข้อต่อรอบ แสดงคำอ่าน ออกเสียงอัตโนมัติ ธีม (ตามระบบ/สว่าง/มืด) ล้างความคืบหน้าแยกภาษา เวอร์ชัน และ "มีอะไรใหม่"
- **คู่มือการเล่น** อยู่ในแอป
- **เลขเวอร์ชัน**: แสดงในแอป และเด้งแจ้งเมื่อมีเวอร์ชันใหม่
- **เสียงอ่าน**: ใช้เสียงในตัวของเครื่อง (Web Speech API)

## ใช้บน iPhone / iPad

1. เปิดลิงก์ GitHub Pages ใน Safari
2. แตะ **แชร์** แล้วเลือก **เพิ่มไปยังหน้าจอโฮม** และเปิด "เปิดเป็นเว็บแอป" ไว้
3. เปิดจากไอคอนบนหน้าโฮม แอปจะเปิดเต็มจอ มีหน้าเปิดแอป และใช้งานออฟไลน์ได้

มีไอคอนครบทุกขนาด (180/167/152/120 รวมถึงไอคอน maskable) และหน้าเปิดแอปของ iPhone 16/17 Pro Max และ iPad Air 11"/13" ทั้งแนวตั้ง/แนวนอน และโหมดสว่าง/มืด

## ลิขสิทธิ์และการนำไปใช้เชิงพาณิชย์

- **ชุดคำศัพท์** (`data/`) เขียนขึ้นใหม่ทั้งหมดและเผยแพร่แบบ **CC0 1.0 (สาธารณสมบัติ)** จึงใช้ แก้ไข หรือขายได้ฟรีโดยไม่ต้องใส่เครดิต (ดู [`data/LICENSE`](data/LICENSE))
- **โค้ด** ใช้สัญญาอนุญาต **MIT** (ดู [`LICENSE`](LICENSE))
- ชุดที่ตั้งใจไม่ใช้: Oxford 3000/5000 (ติดลิขสิทธิ์), NGSL/NAWL (CC BY-SA), รายการคำของ TOPIK/JLPT (เงื่อนไขไม่ชัดเจน)

## การอัปเดตแต่ละครั้ง (เวอร์ชันและ log)

```bash
node scripts/bump-version.mjs minor     # patch | minor | major → แก้ version.js และเพิ่มรายการใน data/changelog.json
# เขียนรายการที่เปลี่ยนใน data/changelog.json (ทั้ง th และ en)
node scripts/bump-version.mjs --sync    # สร้าง CHANGELOG.md ใหม่
node scripts/validate.mjs               # ต้องขึ้น OK
```

- ใช้ semver: **patch** สำหรับแก้บั๊กหรือคำผิด, **minor** สำหรับฟีเจอร์ใหม่หรือคำศัพท์/ภาษาใหม่, **major** สำหรับการเปลี่ยนที่ไม่เข้ากับของเดิม
- ทุกครั้งที่ deploy, GitHub Actions จะเติมเลข build (`<run number>.<commit>`) ให้อัตโนมัติ เช่น `v1.1.0 · build 12.abc1234`
- CI จะไม่ผ่านถ้า PR แก้ไฟล์แอปแต่ไม่เปลี่ยนเวอร์ชัน หรือถ้า changelog/CHANGELOG.md ไม่ตรงกัน
- ถ้าแก้วิธีเล่น ให้อัปเดตคู่มือที่ `assets/js/guide.js`, `CLAUDE.md` (หัวข้อ "What the app can do") และรายการฟีเจอร์ใน README นี้ด้วย
- เมื่อทำเสร็จ: commit เป็นภาษาไทย เปิด PR เข้า `main` รอ CI ผ่านแล้ว merge

## โครงสร้างโปรเจกต์

ดูรายละเอียดทั้งหมดได้ที่ [`CLAUDE.md`](CLAUDE.md) (สรุปโครงสร้าง รูปแบบข้อมูล และข้อตกลงของโปรเจกต์)

```
index.html, version.js, sw.js, manifest.webmanifest
assets/css/style.css
assets/js/       app (router + tab bar), practice, game, progress, settings, info/guide, icons, i18n, store, theme, speech
assets/icons/    ไอคอนและหน้าเปิดแอป (สร้างด้วย scripts/make-icons.py)
data/            languages.json, changelog.json, vocab/<code>.json
scripts/         validate.mjs, bump-version.mjs, make-icons.py
```

### เพิ่มภาษาที่จะเรียน

1. สร้าง `data/vocab/<code>.json` (ดูรูปแบบใน CLAUDE.md)
2. เพิ่มรายการใน `learn` ของ `data/languages.json`
3. เพิ่มไฟล์ใน `CORE` ของ `sw.js`
4. bump เวอร์ชันแบบ minor แล้วเขียน changelog

### เพิ่มภาษาคำแปล

เพิ่ม `tr.<code>` ให้ครบทุกคำ แล้วเพิ่มภาษาใน `translate` ของ `data/languages.json` (ถ้าอยากให้ UI เป็นภาษานั้นด้วย ให้เพิ่มข้อความใน `assets/js/i18n.js` และ `assets/js/guide.js`)
